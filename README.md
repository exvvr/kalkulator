# Kalkulator

SImple console calculator enter a choose an operator then enter b and get a result. download version for your system:
https://github.com/exvvr/kalkulator/releases/latest

## Windows
download `kalkulator-Windows.exe`and run. 

## Linux
```
curl -L -o kalkulator https://github.com/exvvr/kalkulator/releases/latest/download/kalkulator-Linux
chmod +x kalkulator
./kalkulator
```

## macOS
```
curl -L -o kalkulator https://github.com/exvvr/kalkulator/releases/latest/download/kalkulator-macOS
chmod +x kalkulator
./kalkulator
```
